# **App Name**: QuizCraft AI

## Core Features:

- Manual Input Mode: Enable manual entry of subject, grade/class, and topics to define the question paper's scope.
- Document Upload: Support document uploads (DOCX, PDF) for syllabus or content ingestion.
- Content Understanding: Use a tool to analyze and understand content from manual inputs or uploaded documents for question generation.
- Question Generation: Use a tool to generate a variety of question types (MCQ, Short Answer, Long Answer, Fill in the Blanks) based on the defined parameters and difficulty levels.
- Answer Key Generation: Automatically generate answer keys for each question generated by the tool.
- Question Editing: Provide an interface for users to edit, delete, reorder, or regenerate questions, ensuring customization and accuracy.
- Export Functionality: Offer options to export the final question paper in PDF or DOCX format, with or without the answer key.

## Style Guidelines:

- Primary color: Black (#000000) to provide a sleek look.
- Background color: White (#FFFFFF).
- Accent color: Gray (#808080) to provide a contrasting but calm emphasis.
- Body and headline font: 'Inter', a sans-serif font for a modern and neutral feel.
- Code font: 'Source Code Pro' for displaying any code snippets (if applicable).
- Use clean, professional icons related to academic subjects and question types.
- Maintain a structured layout with clear sections for input, generation, editing, and export.
